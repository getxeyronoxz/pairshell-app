## Reporting a Vulnerability

PairShell takes the security of host machines, cryptographic pairing, and terminal tunnels seriously.

If you believe you have found a security vulnerability in PairShell CLI or the Android application, please report it via email to:

xeyronox@outlook.com

Please include:
1. Type of vulnerability and affected component (core, cli, ndroid, 	ransport).
2. Step-by-step reproduction instructions or proof-of-concept.
3. Impact assessment.

**Do NOT report security vulnerabilities through public GitHub Issues.**
